# 分享与部署指南

> 目标：把这个「中山大学深圳校区充电桩实时看板」分享给别人，在别人的电脑或手机上运行。
> 回答核心问题：**做网址，还是做安装包？** —— 结论：**优先「一键启动包」，网址（公网部署）作为进阶选项。**

---

## 0. 先说清一件事：为什么不能做成纯网址

这个项目的本质是「**常驻在本地的采集服务 + 网页界面**」，不是一组静态网页文件：

```
青春号平台接口  ──(每 60 秒采集)──>  本机 Python 后端 + SQLite 历史库
                                          │
                                          ├─ /api/state 提供数据
                                          └─ 网页读取 /api/state 渲染看板
```

- 「预计转空闲时长」依赖**本地 SQLite 累积的历史样本**（已运行 25+ 小时、700+ 样本），换一台设备从零开始就要重新积累。
- 平台接口不允许浏览器跨域直连，必须有一个后端代调。

因此：
- ❌ **不能**像普通静态网站那样丢到 GitHub Pages / Vercel 就完事。
- ✅ 可以做成**一键启动包**（本机跑后端 + 浏览器看），立刻能用、零成本。
- ✅ 也可以**部署到公网服务器**变成真正的网址，但要多一台云主机（见第 4 节）。

另外必须明确的：**手机无法独立运行这个后端**。exe 只在 Windows 上跑；手机是通过浏览器访问局域网里那台电脑的服务（电脑开机、看板运行）。

## 1. 方案对比

| 维度 | 一键启动包（推荐） | 公网网址（进阶） |
|---|---|---|
| 交付物 | 一个 10MB 的 zip | 一个 URL |
| 对方门槛 | 解压 + 双击 bat | 打开浏览器 |
| 电脑要求 | Windows，需保持开机运行 | 无需（服务在云上） |
| 手机访问 | 同一 WiFi 访问电脑局域网 IP | 任意网络 |
| 成本 | 0 元 | 云服务器约 ¥30~100/月 |
| 历史数据 | 每台设备各自累积 | 集中累积，所有人共享 |
| 凭证(token) | 每人各自配置（或共享一份） | 服务端统一配置一次 |
| 适合场景 | 给同学、舍友、小范围分享 | 面向全校、长期稳定服务 |

**建议路径**：先用一键启动包满足「分享给别人」；如果反馈好、需要异地/长期访问，再考虑公网部署。

## 2. 一键启动包（当前已打包好）

### 2.1 交付物位置

```
<项目目录>\dist_包\
├── 中大深圳充电桩看板-一键启动包.zip      ← 发给别人的就是这个（约 10MB）
└── 中大深圳充电桩看板-一键启动包\         ← 展开后的目录（可本地先试）
    ├── SYSUChargeWatch.exe       程序主体（onedir，需配 _internal）
    ├── _internal\                运行时依赖（不要删）
    ├── 启动看板.bat              双击启动（端口 8787）
    ├── 启动看板-备用端口.bat      8787 被占用时用（端口 8788）
    ├── README-先看我.txt         给对方看的图文说明
    ├── web\                      网页 + 离线地图瓦片 + 平台图标
    └── data\
        ├── sites.json            校区/点位配置
        ├── config.json           凭证配置（初始为空模板）
        └── watch.db              首次运行后自动生成的历史库
```

### 2.2 分享步骤

1. 把 zip 发给对方（微信 / 邮件 / U 盘均可）。
2. 对方解压到任意目录（建议路径不要太深）。
3. 双击「启动看板.bat」→ 弹出黑色窗口（不要关）→ 浏览器自动打开 `http://127.0.0.1:8787/`。
4. 手机看：手机连同一 WiFi，打开窗口里显示的「局域网地址」。

### 2.3 打包/重新构建

如果改了代码要重新打包：

```bat
cd <项目目录>
python tools\pack_build.py
```

脚本会：清理旧产物 → PyInstaller 打包（onedir）→ 复制 web/data 模板 → 写启动器与说明 → 压缩成 zip。
关键点：
- 用 `app_paths.py` 做路径兼容层，源码运行和打包运行共用一套目录约定；打包后 `web/`、`data/` 放 exe 同级，数据持久化、可见、可备份。
- **不要把 `data/watch.db` 和真实 token 打进包**（脚本已做空模板处理），对方从零开始。

### 2.4 已完成的实测（2026-11-20）

- 从**中文路径**目录运行 exe 成功（onedir 模式规避了 onefile 的临时目录 + 中文路径 DLL 问题）。
- `/api/state` 返回 6 点位 / 48 电柜 / 199 空闲；`/api/meta`、`/` 首页、marker 图标均 200。
- 打包版网页含自动解析函数（`parseCaptureText`），凭证面板存在。
- 数据正确写入 exe 同级 `data/watch.db`。

## 3. 降低凭证(token)获取门槛 —— 一键粘贴自动解析

### 3.1 背景（为什么必须抓包一次）

平台（青春号 TOSUN，appid `wx98d7c7d09b88b452`）真正的登录链路是：

```
wx.login() 拿 code → getLoginStatus → 微信 getPhoneNumber 授权(encryptedData+iv)
                  → wechatLoginOrReg 拿用户信息与 token
```

**强依赖微信生态**，无法在普通网页/PC 上复现。而短信验证码路径的端点已全部下线（2026-11-20 实测）：

| 端点 | 结果 |
|---|---|
| `/v1/loginRegister/sendCode` | 404 已下线 |
| `/v1/loginRegister/loginOrReg` | 404 已下线 |
| `/v1/user/sendCode` | 404 |
| `/v1/user/wechatLoginOrReg` | 404 |
| `/v1/user/getLoginStatus` | 404 |
| `auth.fetchAccessTokenWithRefreshToken`（uni-app 云开发通用代码） | 与业务 token 无关 |

所以「输手机号+验证码登录」在本项目上做不到——是平台限制。

### 3.2 我们做的简化：一键粘贴自动解析

不配置任何凭证，看板默认可用（空闲/占用/故障统计 + 现场位置编号 + 基于历史的「预计转空闲」）。

要解锁**逐桩位真实已充时长/开始时间/电量/电压电流**，只需抓包一次。为降低门槛，凭证面板新增「一键粘贴」：

1. 用 Fiddler 抓到任意一条 `cloud.tosunelectric.com` 请求。
2. 把整条请求（含请求头）复制。
3. 粘贴进看板「登录凭证」区的「一键粘贴」框，点「识别并填入」——前端正则自动提取 `token`（96 位）与 `mobile`（11 位），无需手动找字段。
4. 点「保存并验证」，后台异步拉取逐桩位真实数据，稍后自动切换。

解析逻辑（纯本机、不联网）：
- token：匹配请求头 `token: <24+位十六进制>`，兜底匹配任意 32~128 位十六进制串。
- mobile：匹配 `mobile=<11位>` 或 `"mobile":"<11位>"`，兜底匹配任意 11 位手机号。
- 已用真实抓包日志验证（token 96 位、mobile 11 位正确识别）。

### 3.3 抓包教程（图文步骤，约 3 分钟）

> 目标：截获一条 `cloud.tosunelectric.com` 的请求，拿到里面的 `token`（请求头）和 `mobile`（请求参数）。
> 拿到后贴进看板「一键粘贴」框 → 识别填入 → 保存验证即可。
> 更细的原理与固件字段说明见 `docs/抓包获取Token指南.md`。

#### 准备工作

| 工具 | 适合 | 说明 |
|---|---|---|
| **Fiddler Classic** | Windows，最省事（下面主线用它） | 免费，图形界面，自动配系统代理；抓 HTTPS 需在 Options → HTTPS 装根证书 |
| mitmproxy | 命令行 / macOS / Linux | `pip install mitmproxy` 后跑 `mitmweb`，证书首次访问 `mitm.it` 安装 |
| Stream（iOS）/ 小黄鸟 HttpCanary（Android） | 手机端直接抓 | 用 VPN 模式，同样要装它的 CA 证书 |

#### 第 1 步：让手机流量经过电脑（中间人代理）

1. 手机和电脑连**同一个 WiFi**。
2. 查电脑局域网 IP：`ipconfig`，看无线网卡的 `IPv4 地址`（如 `192.168.1.23`）。
3. Fiddler → `Tools → Options → Connections` → 勾选 **Allow remote computers to connect**，端口默认 `8888`，点 OK 后**重启 Fiddler**。
4. 手机 WiFi 设置 → 长按当前网络 → 修改网络 → 显示高级选项 → 代理设为「手动」：
   - 主机名：电脑的 IP（如 `192.168.1.23`）
   - 端口：`8888`
5. 手机浏览器打开 `http://电脑IP:8888`，下载安装 **FiddlerRoot certificate**：
   - Android：设置 → 安全 → 从存储设备安装；部分机型要先设锁屏密码。
   - iOS：会提示装描述文件（设置 → 通用 → VPN与设备管理）；装完还要到 设置 → 通用 → 关于本机 → 证书信任设置 把开关打开。

> 代理设好后手机所有 HTTPS 流量都经电脑转发。**用完记得关掉手机代理**，否则电脑一关手机就没网。

#### 第 2 步：触发一条带 token 的请求

1. **先彻底退出微信再重开**（重要！否则微信走缓存直连，不过代理）。
2. 打开「青春号 TOSUN」小程序，正常微信一键授权手机号登录。
3. 点一个会读登录态的页面，比如「我的」→ 账户信息，或充电入口——页面出现手机号/余额/订单，说明已发出带 token 的请求。
4. Fiddler 左侧会话列表找 `cloud.tosunelectric.com`（Ctrl+F 搜 `tosunelectric`），路径常见为 `/v1/user/checkTokenValid`、`getUserInfo`、`checkCabinetInfo`、`getCaboxListByCabinetNo` 之一。

#### 第 3 步：复制整条请求

1. 点中那条请求 → 右侧 `Inspectors → Raw`（原始请求）。
2. **整条复制**（从请求行、请求头到 body 全选复制）——看板的「一键粘贴」会自动识别 token 和手机号，不用自己找字段。
3. 若想手动核对：请求头里找 `token: <一长串>`，body 里找 `mobile=<11位>`。

> 找不到 `token:` 头？确认：① 证书装好且已信任（Fiddler 里请求显示为可展开的明文）；② 点进了需要登录的页面；③ 微信已完全退出重开、流量确实经过代理。

#### 第 4 步：贴进看板

1. 看板「登录凭证（可选）」面板 → 粘进「一键粘贴」框 → 点 **识别并填入**（会提示识别到的 token 位数与脱敏手机号）。
2. 核对下方 token/mobile 字段 → 点 **保存并验证**。
3. 成功后状态栏显示：`凭证有效 · 手机号 1xx****xxxx · 已接入 N 台电柜的逐桩位真实数据`。
4. 桩位卡片上占用桩会带橙色「**实测**」标签，并显示真实已充时长、开始时间、电量/电压/电流、目标时长、预计结束。
   - 固件采样是轮转的：每轮约 180 端口、约 2 分钟，刚配完部分桩位可能还是推算值，等 1~2 轮即全部为真值。

#### token 过期了怎么办

token 过期后看板会自动退回公开模式（不崩）。处理：手机小程序里点一个需登录的页面刷新会话 → 重抓一次 token → 看板点「保存并验证」或「重新验证」。点「清除」可回到纯公开模式。

#### 常见问题

- **Fiddler 里是加密乱码**：CA 证书没装/没信任，重装并信任用户 CA（安卓 7+/iOS 10+ 要在系统设置里额外信任）。
- **小程序不走代理**：个别机型对小程序走独立网络栈，改用手机端 VPN 类工具（Stream / 小黄鸟）或路由器透明代理。
- **复制后验证失败**：token 可能过期，或复制带了多余字符——只复制纯字符串，重新抓。

#### 安全与边界（务必读）

- token **等同于账号凭证**，能读你的手机号/余额/订单，别截图外发、别贴群聊、别提交 Git。
- 看板只把 token 存**你自己电脑**的 `data/config.json`，只调只读状态接口，不发任何充电/支付/下单/启停操作。
- 抓包时代理能看到手机所有 HTTPS 明文，只在自己设备、可信网络操作，用完关代理。
- 本工具是个人学习性质的非官方项目，与青春号平台无关；请遵守平台条款，不要高频抓取、不要转发凭证。

> 如果连抓包都不想让对方做，也可以由你抓一份有效 token 打包进 `data/config.json` 统一分发——但 token 会过期/与账号绑定，共享账号有合规风险，需自行权衡。

## 4. 公网部署（进阶，变成真正的网址）

如果要把服务集中部署、让所有人通过网址访问：

1. 租一台云服务器（Ubuntu 20.04+，约 ¥30~100/月）。
2. 装 Python 3.8+（项目零第三方依赖，无需 pip install）。
3. 上传源码 + web + data（含配置好的 config.json）。
4. 启动（后台常驻，绑 0.0.0.0）：

   ```bash
   nohup python server.py --host 0.0.0.0 --port 8787 > server.log 2>&1 &
   ```

5. 安全组开放 8787 端口；用 Nginx 反向代理 + 可选域名/HTTPS（更专业）。
6. 用 `systemd` 或 `supervisor` 做进程守护，避免服务挂掉。

注意：
- 公网部署时 token 集中放服务端配置一次即可，所有访问者共享同一份历史数据（模型更准）。
- 涉及账号 token，服务器安全（防火墙、HTTPS、访问控制）要到位。
- 这是把「安装包」换成「网址」的唯一正经途径，但需要长期运维成本。

## 5. 给用户的最终建议

- **现在立刻分享**：发 zip，对方双击 bat 即用，手机同 WiFi 访问。零成本、门槛最低。
- **凭证问题**：默认功能（空位统计 + 预计转空闲）无需任何配置就能用；想要逐桩位真实时长再按「一键粘贴」抓包一次（已尽量简化）。短信验证码登录平台已下线，无法实现，需如实告知对方。
- **长期/大规模**：反馈好再上公网服务器，变成真正的网址。
