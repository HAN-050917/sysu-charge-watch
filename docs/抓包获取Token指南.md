# 抓包获取 Token 指南

> 目标：拿到青春号 TOSUN 小程序请求的 `token`（请求头）和 `mobile`（请求参数），一起粘贴到看板「登录凭证」面板，解锁**逐桩位真实状态、已充时长与精确结束时刻**。
>
> 为什么需要它：不登录时，平台只公开电柜的汇总数（空闲/占用/故障各多少），逐桩位明细藏在 `getCaboxListByCabinetNo` 等接口后面，**必须同时带真登录 token 和手机号两个参数**（缺 `mobile` 会返回「登录状态已经失效」）。看板在公开模式下显示的桩位编号、已充时长都是**推算值**。
>
> 配置凭证后能拿到的东西（按可靠度排序）：
>
> | 数据 | 来源 | 精度 |
> |---|---|---|
> | 真实物理桩位号 | `getCaboxListByCabinetNo` 的 `port` | 真值 |
> | 开始时刻 | 同上 `startTime` | 精确到秒 |
> | **已充时长** | 桩端固件 `queryBoxInfo` 的 `ct` | 精确（与 `now − startTime` 中位偏差 2.5 分钟） |
> | 电量 / 电压 / 电流 | 固件 `eg` / `vo` / `am` | 实时真值 |
> | **目标时长** | 固件 `cs=6` 时 `ct` 冻结在目标值上 | `cs=6` 精确；`ct ≥ 420` 精确；其余按档位分布推断 |
> | **预计结束时刻** | `startTime + 目标时长` | 目标确定时精确到秒 |
>
> ⚠️ 平台 `chargeTime` 字段实测**恒为 `null`**，`endTime` 恒等于 `updateTime`（每次刷新时间，**不是充电结束时间**）——
> 这两个字段看着像时长，实际全是废的。真计时器在桩端固件里。

---

## 0. 先想清楚：没有「扫码登录」这回事

青春号小程序**没有**独立的扫码/手机号验证码登录入口给我们用。它的登录是微信小程序内一键授权手机号（`wx.login` → `getLoginStatus` → `wechatLoginOrReg`），密钥和加密数据只在微信运行时里，外部无法构造。

所以能走的路只有一条：**你自己在微信里正常登录一次小程序，把这一次请求里的 token 截下来，贴给看板用。** 这就是本指南要做的事。

token 与你的账号绑定，等同于临时身份凭证。请只在自己的电脑上操作，不要把 token 发给任何人、不要提交到代码仓库。

## 1. 需要的工具（三选一）

| 工具 | 适合 | 说明 |
|---|---|---|
| **Fiddler Classic** | Windows 用户，最省事 | 免费，图形界面，自动配系统代理；抓 HTTPS 需在 Tools → Options → HTTPS 里装根证书 |
| **mitmproxy** | 命令行用户 / macOS / Linux | `pip install mitmproxy`，运行 `mitmweb` 打开网页界面；根证书在首次访问 `mitm.it` 时安装 |
| **Charles / Stream / 小黄鸟** | 手机端抓包 | iOS 用 Stream、Android 用 HttpCanary（小黄鸟）；同样需要安装其 CA 证书 |

下面以 **Fiddler Classic + 安卓手机** 为主线讲解，其他工具步骤大同小异。

---

## 2. 让手机流量经过电脑（中间人代理）

1. 电脑和手机连 **同一个 WiFi**。
2. 查电脑的局域网 IP：
   - Windows：`ipconfig`，看无线网卡的 `IPv4 地址`，例如 `192.168.1.23`。
   - macOS/Linux：`ifconfig` 或 `ip addr`。
3. 打开 Fiddler → 右上角 `Tools → Options → Connections`，勾选 **Allow remote computers to connect**，端口默认 `8888`，点 OK 后**重启 Fiddler**。
4. 手机 WiFi 设置 → 长按当前网络 → 修改网络 → 显示高级选项 → 代理设为「手动」：
   - 主机名：电脑的 IP（如 `192.168.1.23`）
   - 端口：`8888`
5. 手机浏览器打开 `http://电脑IP:8888`，点页面里的 **FiddlerRoot certificate** 下载并安装 CA 证书：
   - **Android**：设置 → 安全 → 从存储设备安装 → 选下载的文件；部分机型需要设置锁屏密码才能装。
   - **iOS**：会提示去 设置 → 通用 → VPN与设备管理 安装描述文件；装完还要到 设置 → 通用 → 关于本机 → 证书信任设置 里把该证书开关打开。

> 代理设好后，手机所有 HTTPS 流量都会被电脑上的代理转发。用完记得把手机代理关掉，否则电脑一关手机就没网。

---

## 3. 触发一次带 token 的请求

1. 手机上打开**微信**，进入「青春号 TOSUN」小程序，正常完成登录（微信一键授权手机号）。
2. 在小程序里点一个会读取登录态的页面，例如「我的」→ 账户信息，或直接进入充电/扫码入口。只要页面上出现了你的手机号、余额、订单等信息，就说明它发出了带 token 的请求。
3. 回到电脑 Fiddler，在左侧会话列表里找域名为 `cloud.tosunelectric.com` 的请求（可以按 Ctrl+F 搜索 `tosunelectric`）。路径通常是这些之一：
   - `/v1/user/checkTokenValid`
   - `/v1/user/checkCabinetInfo`
   - `/v1/user/getUserInfo`
   - `/v1/user/getCaboxListByCabinetNo`

---

## 4. 取出 token

1. 在 Fiddler 里点中那条 `cloud.tosunelectric.com` 请求 → 右侧选 **Inspectors → Raw**（原始请求）。
2. 在请求头里找这一行：

   ```
   token: eyJhbGciOiJIUzI1NiJ9....
   ```

   （也可能同时有 `auth: xxx`，我们要的是 `token`。）

3. 冒号后面那一长串就是 token。复制**整串**，注意不要带上 `token:`、空格或换行。
4. 有的请求会把 token 放在 `POST` 的 form body 里而不是请求头——那种不是我们要的，请找请求头里带 `token:` 的那条。

> 找不到 `token:` 头？确认两点：① 手机确实装了并信任了 Fiddler 证书，HTTPS 请求能被解密（Fiddler 里域名显示为蓝色/可展开的明文请求）；② 你在小程序里点进了需要登录的页面，而不是只有首页。

---

## 5. 把 token 贴进看板

1. 启动看板后端：`python server.py`，浏览器打开 `http://127.0.0.1:8787`。
2. 页面顶部「**登录凭证（可选）**」面板里，把 token 粘贴到密码框。
3. 点 **保存并验证**。看板会：
   - 把 token 存到本机 `data/config.json`（不会写进浏览器、不会进网址）；
   - 立即调用 `checkTokenValid` 验证；
   - 验证通过后，并发拉取全校区电柜的逐桩位真实数据。
4. 面板下方会显示结果，例如：

   ```
   凭证有效 · 手机号 138****0000 · 已接入 47 台电柜的逐桩位真实数据（423 个占用桩位）。
   ```

   同时，桩位时间线里的占用卡片会带橙色「**实测**」标签，并显示桩号、充电状态和电量；「已充」变为桩端固件真实计时值，不再带「至少」二字。点开桩位详情还能看到：
   - **目标时长**：用户下单时选的那几个小时（`cs=6` 到点断电时是精确值，否则带推断概率）
   - **预计结束**：`开始时间 + 目标时长`，目标确定时**精确到秒**
   - **预计剩余**：目标确定时是精确值，否则显示「至多 N 分钟」的上界

   > 固件采样是**轮转**的：每轮 180 个端口、约 2 分钟，全校区 370 个待采端口 2 轮就能走完一遍。
   > 其中「到点断电/手动停止/故障」这类异常端口**排在最前面**，所以第一轮（约 2 分钟）就能看到它们。
   > 刚配置完凭证时部分桩位可能还显示推算值，等 1~2 轮后就都是固件真值了。

## 6. token 过期了怎么办

token 有有效期，过期后接口会返回「会话过期，请重新登录」，看板会自动退回公开推算模式（不会报错崩溃）。这时：

1. 回到手机小程序，随便点一个需要登录的页面刷新会话；
2. 重新按第 3、4 步抓一次 token；
3. 在看板里点 **重新验证** 或直接再次「保存并验证」。

也可以点面板里的 **清除** 回到纯公开模式。

## 7. 安全与边界（请务必读）

- **token 等同于你的账号凭证**，能读到你的手机号、余额、订单等信息。不要截图外发、不要贴到群聊、不要提交到 Git。
- 本看板只把 token 存在**你自己电脑**的 `data/config.json`，只用于调用平台**只读**的状态查询接口（`checkTokenValid` / `getCaboxListByCabinetNo` / `queryBoxInfo`）；不会发起任何充电、支付、下单、启停操作。
- 固件采样对平台是有负载的（单次 `queryBoxInfo` 约 0.7 秒）。看板每轮只采 180 个端口、带双 TTL 缓存与轮转游标，**请不要把 `poll_interval` 调得过低**，也不要在多个实例上同时跑同一份 token。
- 抓包时电脑上的代理能看到手机上所有经过它的 HTTPS 明文。请只在可信网络、自己的设备上操作，用完关闭手机代理与 Fiddler。
- 本工具是个人学习性质的非官方项目，与青春号 TOSUN 平台无任何关联。请遵守平台服务条款，不要高频抓取、不要转发凭证。

## 8. 常见问题

**Q：Fiddler 里请求是加密的乱码，看不到 token 头？**
A：CA 证书没装好或没信任。按第 2 步重装证书；安卓 7+ / iOS 10+ 需要在系统设置里额外信任用户 CA。

**Q：小程序完全不走代理？**
A：个别机型/微信版本对小程序走独立网络栈。可尝试：关闭 WiFi 代理改用 VPN 类抓包（如 Stream/小黄鸟的 VPN 模式），或在路由器上做透明代理。

**Q：找到了 token 但验证失败（提示会话过期）？**
A：token 可能已过期，或复制时带了多余字符。重新抓一次，确保只复制冒号后的纯字符串。

**Q：验证成功但某些电柜还是「推算」？**
A：这些电柜可能离线，或本次逐桩位拉取部分失败。看板对拉不到真实数据的电柜自动降级为推算，并在桩位卡片上如实标注。

**Q：可以做到完全自动、不用手动抓包吗？**
A：不行。登录凭证只存在于微信运行时的加密数据里，外部程序无法合法获取；这也是为什么本项目选择「用户手动提供 token」而不是伪造登录。
