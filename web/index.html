    等级定义、推算方法与免责声明

    五档空闲等级（四档在线 + 离线）

    • 充裕 > 40% 空闲率高于 40%，基本随时可充
    • 一般 15%–40% 有空位但不多，可能需要等一批
    • 紧张 0%–15% 仅剩零星空位，建议看其他点位
    • 已满 0 空位 在线电柜确实没有空闲桩位，需等待空出
    • 离线 无读数 电柜失联，桩位状态未知；不计入空闲/占用统计

    颜色仅作辅助，等级始终以文字标签为准。「已满」与「离线」含义不同：前者是确认没空位，后者是完全不知道。

    「已充时长 / 剩余」怎么来的

    1. 每 60 秒采集每台电柜的空闲数 chargeable。
    2. 空闲数下降，记为一次新占用；上升，则按先入先出取出一条完整充电记录。
    3. 用完整记录算中位充电时长；仍在占用的桩位：已充 = 现在 − 入队时间，剩余 = 中位时长 − 已充。
    4. 斜纹条段表示推算出的剩余时间，实心条段表示已发生的占用时间。

    平台只公开电柜汇总数，逐桩位明细需登录，故本页时长为推算值。

    读数请按区间理解：「至少已充 X」的起点是服务器第一次看见该桩位被占用，不是真实插枪时间；所以剩余时间对应是「至多还剩 Y」。当前真实完整充电记录为 0 条时，全部时长按 180 分钟经验先验推算，卡片上会标注「经验先验」。
